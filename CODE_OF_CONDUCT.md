# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- be respectful and constructive
- assume good faith
- no harassment, personal attacks or discriminatory language
- keep discussions about the work

**Reporting.** To report unacceptable behaviour, use GitHub's **Report content** option or contact the maintainers privately through the repository's security advisory form. Reports are handled confidentially.

**Consequences.** Maintainers may remove comments, commits or contributions that break these rules, and may ban repeat offenders.
